📖 Dictionary App

A simple Dictionary App built using Python. 
It allows users to search for words and view their meanings.

✨ Features

🔍 Search for words

📖 Display word meanings

❌ Shows message when a word is not found

🔄 Search multiple words

🚪 Exit the app


🛠️ Technologies Used

Python

Dictionary

while loop

if-else

User input


🎯 Learning Purpose

This project helps practice:

Python dictionaries

while loops

Conditional statements

input()

String methods
